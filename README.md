## 🇮🇳 The Problem & Executive Summary

Every year, millions of travelers descend upon a handful of ultra-saturated tourist corridors (Shimla, Manali, Mussoorie, Ooty, Goa). The consequences are catastrophic:

- **12+ hour bumper-to-bumper traffic paralysis** on fragile mountain highways.
- **Municipal water shortages & rationing** (Shimla faces a 4.8 MLD daily water deficit during peak weeks).
- **Slope instability, unmanageable landfill waste**, and degradation of fragile Himalayan and coastal biospheres.
- **The Paradox**: While core hill stations are collapsing under overtourism, picturesque heritage villages just **20–30 km away** suffer from economic neglect and under-monetization.

**DeshDarshan AI** solves this systemic challenge. It is an autonomous, national-grade digital operating system that monitors carrying capacities, forecasts crowd surges **3 hours before they happen**, and dynamically rebalances travelers to experience-equivalent rural satellites using open **ONDC (Beckn Protocol)** commerce and **Green Karma (DeshCredits)** incentives.

## 🌟 10 Operational Modules

1. **AI Tourism Demand Rebalancer (Flagship Scenario)**:
   - Live detection of saturated choke points (e.g., **Shimla at 94% Saturation**, 3.0 hrs delay, 4.8 MLD water deficit).
   - Autonomous rerouting to **Narkanda at 35% density** (+25 km, 93% scenic match, ₹4,500 rural economic injection).
   - Supported circuits: Shimla &rarr; Narkanda, Manali &rarr; Tirthan/Jibhi, Mussoorie &rarr; Kanatal, Ooty &rarr; Kotagiri, Goa &rarr; Divar Island, Jaipur &rarr; Bundi.

2. **Live Tactical GIS Tourism Heatmap**:
   - Interactive GIS nodes color-coded green (<45%), yellow (45-74%), and red (&ge;75% critical).
   - **Predictive Time Slider (T+0h to T+3h)** forecasting crowd surges from inbound highway toll plazas.
   - Dynamic animated migration corridors guiding tourists to eco-friendly destinations.

3. **Digital Tourism Twin (Carrying Capacity Telemetry)**:
   - Municipal telemetry: Carrying capacity vs current visitors vs surge projections.
   - Tracks water demand (MLD), solid waste diversion (Tonnes/day), and local retention percentage.

4. **Green Karma &bull; DeshCredits System**:
   - Sovereign gamified credit wallet (1,450+ credits) rewarding off-peak & eco-alternative choices.
   - Interactive **Credit Earning Simulation Engine** computing CO₂ saved and rural wealth generated.
   - Redeemable for 25% off verified ONDC homestays, free GI handloom shawls, and zero-wait electric shuttles.

5. **Rural Discovery Engine (30km Radius)**:
   - Automatically triggered whenever an adjacent hotspot breaches 75% critical capacity.
   - Highlights 100-year apple farmstays, GI Kinnauri handloom weavers, and Toda tribal artisans.

6. **ONDC Commerce Integration (Beckn Protocol)**:
   - Open Network for Digital Commerce (BAP &rarr; Gateway &rarr; BPP Node) transaction simulator.
   - Transparent commission comparison: 96% to rural hosts vs 65% on corporate OTAs.
   - Real-time cryptographic ledger with verified transaction hashes.

7. **Voice-Based Rural Host Onboarding (Multilingual Hindi AI)**:
   - Web Speech ASR & natural village Hindi parser designed for non-English rural elders and artisans.
   - Auto-extracts homestay name, village, tariff, category, and amenities into an ONDC Beckn catalog.

8. **Climate & Sustainability Accounting**:
   - Real-time ecological ledger: Carbon avoided (Tonnes CO₂e), vehicle idling hours saved, and fragile valley waste diverted.
   - Interactive National Scaling Simulator.

9. **Ministry of Tourism Command Center**:
   - Central control room with critical saturation early warnings.
   - District intervention policy controls: Dynamic permit throttling, +500 DeshCredit surge bonuses, green shuttle deployment.
   - Instant exportable **Government Intelligence Brief**.

10. **Autonomous Multi-Agent Visualizer**:
    - Live pipeline view of the 5 micro-agents negotiating, verifying carrying capacity, and triggering rebalancing actions.

## 🚀 Getting Started & Local Setup

### Prerequisites
- **Node.js**: `v18.18.0` or higher (Recommended: `v20.x`)
- **npm**: `v9.x` or higher
- **Git**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/itskian2007/bwb-project-5.0.git
   cd bwb-project-5.0
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables** (Optional):
   ```bash
   cp .env.example .env.local
   ```

4. **Launch Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

5. **Build for Production**:
   ```bash
   npm run build
   npm run start
   ```
